# Модуль monitors — монитор событий СКУД

## Назначение

Модуль **monitors** предназначен для отображения событий системы контроля
доступа (СКУД) в режиме реального времени. События выводятся в виде
таблицы с фильтрацией по группам устройств, поддержкой фотографий
сотрудников и цветовой подсветкой по типу события.

## Вызов монитора

Нажмите на пункт меню **«Монитор»** или откройте URL `/monitors`.

## Что предоставляет модуль monitors

Информация выводится в едином журнале событий со следующими блоками
управления:

| Блок | Описание |
|------|----------|
| **Журнал событий** | Таблица событий: ID, тип, дата/время, устройство, сотрудник, организация, код аналитики. |
| **Фильтр по группе** | Выпадающий список групп устройств (`DEVGROUP` верхнего уровня). |
| **Настройки** | Интервал обновления, количество строк, количество окон с фото, автоскролл. |
| **Очистить экран** | Удаляет все события с экрана, не сбрасывая cookie с последним ID. |
| **Сброс** | Полный сброс: очищает cookie и перезагружает последние 30 событий. |
| **Остановить** | Приостановка поступления новых событий (клавиша «Пробел»). |
| **Фотографии** | Включение/выключение всплывающих окон с фото сотрудников. |
| **Статус** | Индикатор соединения: WebSocket / AJAX / Отключен. |

## Блоки информации

| Блок информации | Описание | Где используется |
|------------------|----------|------------------|
| **Журнал событий** | Поток событий в реальном времени. | `monitors`<br>`event`<br>`device_panel` |
| **Группы устройств** | Фильтр по иерархии точек доступа. | `monitors`<br>`device` |
| **Фотографии** | Всплывающие окна с фото сотрудников. | `monitors`<br>`people` |
| **Код аналитики** | Расшифровка кода события. | `monitors`<br>`analit` |
| **Счётчики** | Часы, всего событий, отображается. | `monitors` |

## Порядок работы

**События появляются автоматически** сверху таблицы. Новые строки
подсвечиваются жёлтым.

**Группа устройств**. Выбор в выпадающем списке сохраняется в сессии
и cookie. При следующем открытии монитора фильтр восстанавливается.

**Фотографии**. При включённом чекбоксе «Фотографии» для каждого
события создаётся всплывающее окно с фото сотрудника. Окна можно
перемещать мышью за заголовок.

**Остановка**. Чекбокс «Остановить» или клавиша «Пробел» приостанавливает
поступление событий. Полезно при разборе инцидента.

**Очистить экран** — временно убирает все строки, не сбрасывая позицию
отслеживания. При следующем обновлении загрузятся только новые события.

**Сброс** — полностью сбрасывает cookie и загружает последние 30 событий
заново.

---

## Результат работы

Таблица событий с цветовой подсветкой по типу события, возможностью
просмотра фотографий сотрудников и всплывающими подсказками по коду
аналитики.
